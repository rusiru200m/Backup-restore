Set up SSH access here

The app generates and encrypts a private key on the controller. No key path, key passphrase, or environment variable is needed for generated keys. Keys are named using the profile name above.

Public key for VPS console setup 

          
If SSH password login is disabled, add this public key as a new line in the selected account's ~/.ssh/authorized_keys through your VPS console or existing SSH client. Keep existing keys. The app's private key is never displayed.

        

        
1. Verify the server identity

        
        
Enter the VPS host and port above, then read its SSH fingerprint. Reading alone does not establish trust.

        
        
Compare the fingerprint with your VPS provider console or an existing trusted SSH connection. Paste the verified value here; the app will check it again and save the server identity automatically.

        
        
2. Authorize the generated key

        
        
The password is used only to add the public key to this VPS account. It is not saved. This requires SSH password login; otherwise use the public-key console setup above.
